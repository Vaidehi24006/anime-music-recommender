# Anime Music Recommender

A lightweight anime-style music recommendation app using MongoDB and Express.

## Run locally

1. Install MongoDB locally
2. Start MongoDB:
   ```bash
   mongod
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start app:
   ```bash
   npm start
   ```
5. Open:
   ```bash
   http://localhost:3000
   ```

## Stack
- MongoDB
- Express
- Node.js
- Custom anime neon UI

## Notes
This is a compact recommendation demo using real MongoDB data and simple content-based matching.
